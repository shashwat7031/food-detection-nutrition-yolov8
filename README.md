# Food Detection & Nutrition Analyser (YOLOv8 + Food-101)

Detects food items in photos using a YOLOv8 model trained on the Food-101 dataset (101 food categories), then fetches per-item calorie and macro data from the USDA nutrition API.

---

## What it does

1. Downloads and prepares the Food-101 dataset in YOLO format (~5 GB, first run only)
2. Fine-tunes YOLOv8n on 101 food categories
3. Runs inference on a user-uploaded image
4. Shows an interactive widget to review, rename, and enter gram weights for each detected item
5. Outputs an annotated image and a detailed nutrition table (calories, protein, carbs, fat)

## Requirements

- Python 3.8+
- NVIDIA GPU with CUDA (recommended — CPU training is very slow)
- ~10 GB free disk space (dataset + model weights)

Install dependencies:

```bash
pip install ultralytics pillow pandas requests ipywidgets scipy torchvision
```

---

## How to run

Open `food_detection_nutrition_yolov8.ipynb` in Jupyter Notebook or JupyterLab and run cells top to bottom:

| Cell | What it does |
|---|---|
| 1 | Install packages |
| 2 | Imports, GPU check, and config |
| 3 | Download Food-101 & convert to YOLO format |
| 4 | Fine-tune YOLOv8n (30 epochs, ~15–40 min on GPU) |
| 5–6 | Upload your image and run detection |
| 7 | Interactive widget: fix labels, enter gram weights |
| 8 | Generate annotated output image |
| 9 | Print detailed nutrition summary table |

> **Tip:** If you already have trained weights (`best.pt`), set `SKIP_TRAINING = True` in Cell 4 to skip straight to inference.

---

## Model details

- Base model: YOLOv8n (nano, ~6 MB)
- Dataset: Food-101 (101 classes, 1,000 images per class)
- Training subset: 200 train + 50 val images per class
- Epochs: 30 (increase to 50–100 for better accuracy)
- Input resolution: 640×640
- Precision: FP16 on CUDA GPUs

---

## Notes on liquids

YOLO detects visible regions, so liquids (juice, coffee, soup) are detected via their container. Use the Cell 7 widget to rename the region to the correct drink and enter ml as grams (1 ml ≈ 1 g).

---

## Nutrition data

Calorie and macro data is fetched from the [USDA FoodData Central API](https://fdc.nal.usda.gov/) using a built-in fallback table for common items. No API key needed for basic use (`DEMO_KEY`).

- `runs/` — training output and model weights (generated by Cell 4)
